Hello! The file "final.py" is the final project for John Kull's CSCI 110 Beginning Programming Python class.
What this game does is give the player a range of numbers that differs based on what mode the player chose.
For example, if the player chose easy mode, they will have to guess from a set of numbers that range 1-50.
If they chose the hard mode, the player will have to choose from 1-500.
The game gives the player unlimited attempts to find the number. When the player finally guesses the number, a .txt file
will be saved to their hard drive containing the number of attempts. This file will be displayed upon the next time the player
starts the game.

To select a mode, press 1 or 2 then Enter to start playing.

Thank you for playing my game! Also, P.S. - there is a 'supersecret' hidden somewhere in this game. Good luck finding it!
